# teste final - readme do confluence

## 📝 Introdução
Este projeto, criado por Laura Christine Dromlewicz de Almeida, é uma automação desenvolvida para integrar diversas plataformas, como Confluence, GitHub e OpenAI. O software permite a criação e atualização automatizada de README, documentações e release notes, podendo buscar conteúdo de diferentes fontes (Confluence, Word, PDF, Web), gerar documentos estruturados e publicá-los no GitHub ou Confluence. Além disso, ele gera release notes automaticamente a partir de conteúdos fornecidos.

## 🚀 Visão Geral
Este software é uma ferramenta valiosa para desenvolvedores e equipes que precisam gerar e manter documentações de projetos de software de maneira eficiente. Ele automatiza tarefas repetitivas e garante que as documentações estejam sempre atualizadas e consistentes em todas as plataformas.

## ⚙️ Instalação
Para instalar e configurar o software, siga os passos abaixo:
1. Clone o repositório da automação.
2. Instale as dependências necessárias usando pip. Para isso, execute o seguinte comando no terminal:
```
pip install python-dotenv requests beautifulsoup4 PyGithub openai==0.28 python-docx PyPDF2
```
3. Execute o seguinte comando para instalar a dependência adicional:
```
apt-get install python3-tk
```
4. Crie um arquivo .env com as variáveis de ambiente necessárias. Consulte o exemplo fornecido para obter detalhes.

## 🛠️ Uso
Após a instalação e configuração, você pode começar a usar o software para gerar e atualizar documentações automaticamente. Basta fornecer os conteúdos de origem e o software cuidará do resto.
